# homelight

Telegram-бот, який перевіряє наявність електроенергії в будинку на Полтавській 64
через реле Shelly (Shelly Cloud API) і сповіщає підписників, коли світло зникає
або з'являється.

## Як це працює

- Кожні 90 с бот запитує стан пристрою в Shelly Cloud (`/device/all_status`).
- **Світла немає**, якщо пристрій офлайн (Shelly живиться від мережі, тож без світла
  він зникає з мережі) або якщо напруга нижча за 100 В.
- **Стан невідомий**, якщо не вдалося отримати дані (мережа, ліміт запитів, збій
  Shelly Cloud). Такі перевірки ігноруються й не дають хибних сповіщень.
- Зміна стану **підтверджується повторною перевіркою** через 20 с. Сповіщення
  надсилається лише після двох однакових читань поспіль, тож короткі збої його не викликають.
- Підтверджений стан і час його початку зберігаються в PostgreSQL (таблиця
  `light_state`), тому перезапуск бота не дає повторних сповіщень і не обнуляє
  тривалість відключення.
- Кнопка «🔌 Перевірити наявність електроенергії» показує поточні дані (з кешем на
  30 с) і нічого не змінює в стані сповіщень.
- Користувачі, які заблокували бота, автоматично відписуються.

## Змінні середовища

| Змінна | Обов'язкова | Опис |
|---|---|---|
| `BOT_TOKEN` | так | токен Telegram-бота |
| `SHELLY_AUTH_KEY` | так | ключ авторизації Shelly Cloud |
| `DATABASE_URL` | так | URL PostgreSQL |
| `SHELLY_BASE_URL` | ні | сервер Shelly Cloud (за замовчуванням `https://shelly-237-eu.shelly.cloud`) |
| `TARGET_MAC` | ні | MAC пристрою (за замовчуванням `48f6eeb6ec00`; порожнє значення — перший пристрій) |
| `TIMEZONE` | ні | таймзона для відображення часу (за замовчуванням `Europe/Kyiv`) |
| `DB_SSLMODE` | ні | `sslmode` для PostgreSQL (за замовчуванням `require`; для локальної бази — `disable`) |

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Таблиці в базі створюються автоматично під час старту. Для Heroku-подібних платформ
є `Procfile` (`worker: python app.py`).

## Тести

```bash
python -m unittest discover -s tests -t .
```

Тести SQL (`tests/test_db.py`) запускаються лише з окремою тестовою базою (вони видаляють
таблиці, тому її назва повинна містити `test`):

```bash
TEST_DATABASE_URL=postgresql://user@localhost/homelight_test DB_SSLMODE=disable \
    python -m unittest tests.test_db
```

## Структура

- `app.py` — запуск, обробники команд і кнопок.
- `broadcaster.py` — фонова перевірка й розсилка сповіщень.
- `light_checker.py` — запити до Shelly Cloud, логіка підтвердження стану, тексти повідомлень.
- `db.py` — робота з PostgreSQL.
- `config.py` — налаштування зі змінних середовища.
